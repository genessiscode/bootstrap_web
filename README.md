# TravelEase - Bootstrap 5 Responsive Website

Website frontend using Bootstrap 5 for hotel booking interface.

## Project Structure
- `index.html`: Main HTML file
- `css/styles.css`: Custom CSS with design specifications
- `scripts/scripts.js`: JavaScript functionality
- `assets/`: Images, icons, and other assets
- `member_roles.md`: Team member responsibilities

## Member Responsibilities

**Member 1 - Navbar & Grid Skeleton**
- Built responsive Bootstrap navbar with 5 links (Home, Features, Rooms, About, Contact)
- Implemented container/row/column grid system for home page layout
- Ensured navbar collapses properly on mobile devices

**Member 2 - Cards & Image Handling**
- Created 5+ cards with feature icons and descriptive content
- Implemented responsive image handling with proper sizing and alignment
- Ensured all images use img-fluid classes and proper thumbnail styling

**Member 3 - Button Styles & Booking Form**
- Implemented 5 different Bootstrap button styles with meaningful purposes
- Developed booking form with 4 form controls (check-in date, check-out date, room type, number of guests)
- Added client-side validation with visual feedback (red borders for errors)

**Member 4 - Table & Pricing Display**
- Built room pricing table with 5 room types and availability status
- Applied multiple Bootstrap table styles (striped, hover, bordered, dark)
- Made table responsive with proper horizontal scrolling on small screens

**Member 5 - UI/UX & Design Implementation**
- Applied design specifications: pill-shaped containers (50px border-radius), solid rgb() backgrounds
- Used Helvetica/Arial sans-serif typography throughout (no monospace)
- Brand blue (#2563eb) used only for button hover state
- No hover lifts, fades, or transforms - elements stay in fixed position

**Member 6 - Testing & Finalization**
- Tested website on mobile, tablet, and desktop browsers
- Verified all Bootstrap components work correctly across screen sizes
- Organized project files with proper folder structure
- Created final ZIP package for submission

## Design Specifications
- Pill-shaped containers with 50px border-radius
- Solid rgb() backgrounds (no gradients or glassmorphism)
- Helvetica/Arial sans-serif typography (no monospace)
- Brand blue (#2563eb) only for button hover state
- No emojis, no gradients, no glassmorphism effects
- No cursor-following beam animations
- No em-dashes or inconsistent spacing
- All text in plain, readable format without robotic phrasing

## How to Run
1. Open index.html in any modern browser
2. Test on different screen sizes using Chrome DevTools
3. Verify all interactive elements function properly
4. Compress the project folder into ZIP for submission
